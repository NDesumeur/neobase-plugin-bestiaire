# Bestiaire

L'encyclopédie des **523 créatures** de NeoBase, toutes avec un nom unique, un identifiant (`cr-001` à `cr-523`), un type (ou deux), une rareté, des statistiques, des capacités, un habitat, une description et une illustration pixel générée.

- Grille avec recherche (nom, numéro, capacité), filtres (type, rareté, forme), favoris et tri.
- Fiche détaillée : illustration animée, barres de statistiques, capacités, affinités entre types, description.
- Comparateur de deux créatures.
- Tes favoris et ton tri sont retenus dans le dossier du plugin.

La base des créatures est commune à tous les jeux qui l'utilisent (Cartes, Catacombes) : elle est copiée dans chaque plugin à la fabrication (`neobase-creatures/build.js`), donc chaque plugin reste autonome.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Bestiaire → Installer**.
